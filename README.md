# Про Трансфер — MVP лендинга-калькулятора

Быстрый MVP сайта трансферов (аэропорты, вокзалы, межгород по Крыму и Югу России) по механике
референса `ugtravel.ru`: **маршрут → тариф → цена → заявка**.

Стек: **Vite + Tailwind CSS 4 + Alpine.js + Яндекс.Карты**. Без фреймворка, без бэкенда — данные в JSON.

## Демо

Превью для заказчика: **https://proto0654.github.io/protransfer/**

Деплой — сборка `dist` в ветку `gh-pages` (Pages → Source: ветка `gh-pages`, папка `/`):

```bash
npm run deploy   # build + push dist в gh-pages
```

## Команды

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
npm run preview  # локальный предпросмотр сборки
```

Сборка использует относительные пути (`base: './'` в `vite.config.js`), поэтому `dist/` работает
и из корня домена, и из подпапки вида `/protransfer/` на GitHub Pages.

## Как считается цена

```
км      = расстояние по дорогам: Яндекс.Маршруты (если задан ключ) → публичный OSRM →
          ручное значение из routes.json.overrides, иначе haversine × 1.35 (округление до 5 км)
время   = от того же источника; иначе км / скорость (50–82 км/ч в зависимости от дальности) + 10 минут
цена    = max(минималка, база + км × ставка)
        + туда-обратно ×1.9 (это «−5%» в интерфейсе)
        + 500 ₽ за дополнительную остановку (детское кресло бесплатно)
итог    = округление до 10 ₽
```

«Автобус» помечен `onRequest: true` — цена в интерфейсе показывается как «По запросу».
Число пассажиров ограничивает выбор тарифа: в карточках с малым числом мест появляется метка
«мало мест», при увеличении пассажиров тариф переключается автоматически.

## Выбор точек и карта

- Поля «Откуда»/«Куда» — не `<datalist>`, а собственный список с поиском: по клику показываются
  популярные точки, при вводе — фильтр по названию, городу и алиасам (`ял` → «Ялта»).
  Работают стрелки ↑/↓, Enter, Esc и выбор мышью; клик по полю выделяет старое значение,
  чтобы можно было набрать новое.
- Карта — **Яндекс.Карты JS API 2.1** (`api-maps.yandex.ru/2.1`), блок стоит под заголовком
  калькулятора, выше полей «Откуда/Куда». Точки подписаны «А» и «Б», линия маршрута — тёмная
  с янтарным «свечением», масштаб подбирается по маршруту (`setBounds`, без `checkZoomRange`:
  с ним карта откатывается на обзорный зум и маршрут «тонет» в центре).
- Ключ API прописывается в `src/data/site.json` → `map.apiKey`. Пока ключа нет, карта рисуется,
  но в консоли браузера будет предупреждение `Invalid API key`; для продакшена нужен ключ
  (в кабинете Яндекса должны быть включены «JavaScript API», «API получения деталей маршрута»,
  при желании «Геокодер»).
- Километраж и геометрия: сначала Яндекс (`ymaps.route`) — когда задан ключ; если ключа нет или
  сервис отказал — публичный OSRM (`router.project-osrm.org`); если недоступен и он — остаётся
  собственный расчёт по координатам и прямая линия. Результаты кешируются в памяти браузера.
- Карта инициализируется лениво (IntersectionObserver), скрипт Яндекса подгружается только
  при подходе к блоку; зум колесом включается после клика по карте, чтобы не «съедать» прокрутку.


## Что происходит при отправке заявки

Бэкенда нет, поэтому заявка:

1. валидируется (имя, телефон, согласие, дата и время не в прошлом);
2. сохраняется в `localStorage` (ключ `protransfer_orders`, до 100 записей);
3. показывается в модальном окне с готовым текстом и кнопками «Отправить в WhatsApp»,
   «Telegram», «Скопировать», «Позвонить».

Это полноценный UX-сценарий для демо. Для продакшена нужно заменить шаг 2 на POST на бэкенд и
**пересчитывать цену на сервере** — сейчас она считается на клиенте, и её нельзя принимать как
источник истины (та же уязвимость, что у референса).

Пример точки интеграции: в `src/js/app.js` метод `submitBooking()` — вместо/после `saveOrder()`
отправляйте `fetch('/api/orders', {...})` и показывайте ошибку, если запрос не прошёл.

В политику конфиденциальности перед публикацией нужно добавить пункт о том, что страница
подгружает карту Яндекс.Карт и прокладывает маршрут через сторонний сервис — им передаются
координаты выбранных точек. Персональные данные клиента при этом не отправляются.

## Про данные

Данные референса (`ugtravel.ru`) **не копировались**: ни точки, ни цены, ни тексты, ни фото.
Координаты точек взяты из открытых источников, ставки и минималки — собственные, тексты — написаны
для этого проекта. Формула цены повторяет рыночную механику (`max(минималка, база + км × ставка)`).
Фото машин — стоковые с Unsplash (лицензия Unsplash: бесплатно, в том числе для коммерческого
использования, атрибуция не обязательна). Фон в hero — снимок Крымского моста.
